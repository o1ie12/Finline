# Archive

How Finline was planned and built, kept for the record. Nothing here is
maintained, and parts of it describe designs that were later changed or
switched off. For the current state read the top-level `README.md`,
`docs/database.md` and `docs/backend-roadmap.md`.

Much of this was written by or for AI coding tools (Claude Code): build
specs, running notes, and reports after each round of work.

| Folder | What it is |
|---|---|
| `finline-redesign/` | The spec package for the October 2026 redesign (design system, life game, task engine, content, fix orders). `VERIFIED.md` is still cited from `lib/insurance.ts`. |
| `design/` | Design stop reports, the merge plan and ship log from that redesign, and two design canvases. |
| `playtest-05/` | The report and handoff from the first playtest fixes. |
| `redesign/` | The build plan, running decisions, and dated reports (10 to 13) for each later round, with screenshots. |
| `audit.md` | A September 2026 check that each course's final exercises what the course taught. |

Some files link to preview deployments or a hosting dashboard. Those links
need a team login and most have expired.
